# Employee Dashboard

React assignment with a Home dashboard and a separate Employee form. The dashboard fetches users from [JSONPlaceholder](https://jsonplaceholder.typicode.com/users) and displays their ID, name, and email. The form includes Name, Designation, Location, and Salary. It does not send or save data.

## Run locally

```bash
pnpm install
pnpm dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build

```bash
pnpm build
```

Built with React, React Router, Vite, and Bootstrap.
